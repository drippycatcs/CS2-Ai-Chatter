# Assets for the main README

Drop screenshots and media here, then uncomment the matching block in the root `README.md`.

Suggested files:

| File | Shows |
|---|---|
| `dashboard.png` | The dashboard settings / personality page |
| `ingame.png` | An in-game chat exchange with the bot |
| `demo.gif` | Short capture of a reply happening live (optional) |

**Demo video:** GitHub can host it for you - edit the root README on github.com, drag an `.mp4` into the editor, and it inserts a hosted URL that renders as an embedded player. Replace the `🎬 DEMO VIDEO` comment with that line. Keep it under ~10 MB.

Tip: capture screenshots at ~1600px wide; the README displays them at 800px so they stay sharp on high-DPI screens.
